## 교육 방침 결정

### 탐색 함수는 시작점을 인자로 받는 형태를 기본으로 (2026-08-23)

2178에서 시작점이 `(0,0)` 고정이라 `bfs(void)` 스켈레톤을 제시했으나(사용자는 원래 `bfs(int r, int c)`로 작성했음), 사용자가 "해설들은 인자를 받는데 왜?"라고 지적. **지적이 옳다.**

판단 기준은 "함수를 몇 번 부르는가":

| 상황 | 형태 |
|---|---|
| 고정된 한 점에서 한 번만 | `bfs(void)` 가능 (2178) |
| 시작점 여러 개, 각각 따로 탐색 | **인자 필수** (2667 단지, 2606 바이러스) |
| 시작점 여러 개를 동시에 퍼뜨림 | `bfs(void)` 자연스러움 (7576 토마토) |
| 재귀 DFS | **인자 필수** |

인자 필수인 경우가 더 많고, 인자를 받는 코드는 고정 시작점에도 그대로 쓸 수 있지만 반대는 불가능하다. **손에 익는 형태가 더 일반적인 쪽이어야 하므로 인자형을 기본으로 가르친다.** "이 문제에서 가장 단순한 형태"보다 "앞으로 계속 쓸 형태"를 기준으로 스켈레톤을 제시할 것.
