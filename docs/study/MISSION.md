# Mission: C언어로 코딩테스트 대비 + 자료구조 기초 복원

## Why
예전에 Python으로 삼성 SW 역량테스트 A형을 취득했지만, BFS/DFS/시뮬레이션/트리 등 핵심 패턴이 흐려진 상태. 이번에는 **C언어**로 풀이하면서 코딩테스트 실전 감각을 복구하고, 동시에 자료구조를 직접 구현하며(C에는 내장 컨테이너가 없으므로) CS 기초를 다진다.

## Success looks like
- 큐/스택/힙/해시맵을 C로 라이브러리 없이 직접 구현하고, 문제 풀이에 재사용할 수 있다
- BFS/DFS/시뮬레이션/트리 문제(삼성 A형~백준 골드 수준)를 C로 막힘 없이 푼다
- 문제를 보면 어떤 패턴인지 30초 안에 분류할 수 있다
- 풀이마다 시간/공간 복잡도를 설명할 수 있다

## Constraints
- 풀이 언어는 C (Python 경험은 있으나 C 구현이 병목)
- 하루 최소 1시간, 매일
- Python 시절 지식이 잠재되어 있으므로 "처음 배우기"가 아니라 "복구 + C로 재구현"이 학습의 축

## Out of scope
- 경쟁 프로그래밍(Codeforces 레이팅 등) 수준의 고급 알고리즘
- C++ STL — C 직접 구현이 목적이므로 STL로 우회하지 않는다
- 웹/시스템 등 알고리즘 외 주제
