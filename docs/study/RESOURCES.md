## 문제 출처

- [백준 온라인 저지](https://www.acmicpc.net/) — 국내 코테 대비 주력. 단계별 풀기(`/step`)와 문제 태그로 패턴별 연습 가능
- [solved.ac](https://solved.ac/) — 백준 문제의 난이도(티어)와 태그를 보여줌. 근접발달영역에 맞는 문제 고르는 데 유용

## C 언어 참고

- [cppreference — C 라이브러리](https://en.cppreference.com/w/c) — `qsort`, `scanf` 포맷 등 표준 라이브러리 정확한 시그니처
- gcc 경고 옵션: 항상 `-Wall`로 컴파일. 연쇄 비교(`0 <= x < N`), 미사용 변수, 반환값 누락 등을 잡아줌
